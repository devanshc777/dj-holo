# dj-holo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a browser DJ rig — dual-deck Web Audio engine, hand-tracking control, holographic R3F skin — per the approved spec (`../specs/2026-07-06-dj-holo-design.md`).

**Architecture:** Pure-TS engine behind a facade; input adapters emit uniform ControlEvents into a zustand store which drives the engine; classic 2D UI and holo 3D UI are interchangeable views over the same state.

**Tech Stack:** Vite, React 18, TypeScript strict, zustand, three + @react-three/fiber + drei, @mediapipe/tasks-vision, vitest.

**Execution note (2026-07-06):** User chose inline execution in the originating session; tasks executed in order below, one commit per task. Full code lives in the repo — this plan tracks scope and verification, not duplicated listings.
