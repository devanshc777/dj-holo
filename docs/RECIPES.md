# Transition Recipes

Practice recipes distilled from pro tutorials (full study note:
`C:\Personal\Aethion\knowledge\music\dj-transitions-eq-technique.md`). Keys in `docs/GESTURES.md`.

Prep for all: both decks loaded, incoming deck synced (`E`/`I`).

| Recipe | Steps |
|---|---|
| **Bass swap** (foundation) | B lows → ~15% → B volume in → run 8–16 bars → at a phrase change: B lows up + A lows down together → crossfade → pause A |
| **Soft entry** | same, plus B highs ~30% on entry; restore highs with the swap |
| **Half-rule seat** | B: low 25 / mid 40 / high 40 → volume in → raise gradually → swap |
| **Impact entry** (work down) | cue B just before its drop → at A's section end: B in near-flat and loud |
| **Echo out** (any BPM/genre) | A FX up over last 4 beats → A volume down at phrase end → start B's strong intro on the tail |
| **Breakdown switch** (no beatmatch) | hot-cue both breakdowns → at A's: jump+play B's cue, A lows down + FX up, fade A |
| **Lazy mode** | `M` — automix does sync + 8-bar smoothstep crossfade |

Phrase math: 4 beats = bar; phrases run 8/16/32 bars; land your moves on phrase boundaries.
